ATM LITTLE MUSLIM LEARNERS — RELEASE CANDIDATE NOTES

This package is based on the latest project ZIP supplied for the release preparation.

VERIFIED IN THE SOURCE PACKAGE
1. Daily Tasbih & Dhikr includes a large circular counter, a curated list of adhkar, daily totals, progress, custom counters and local-device saving.
2. The separate Daily Azkar home-page feature is not present. Ayatul Kursi phrase-by-phrase learning remains accessible from the Tasbih & Dhikr page.
3. The trilingual dictionary contains 250 English–Hausa–Arabic entries, with category filtering and browser speech pronunciation.
4. Hisnul Muslim catalogue contains 132 chapters and 267 entries. Selected Hausa meanings are included; remaining entries display a clear notice that a reviewed Hausa translation is not yet available.
5. Developer details are present: Abdussalam Tahir Malumfashi, ATM Digital Solutions & Services, phone and email.
6. The app includes a web app manifest, 192px and 512px icons, HTTPS-compatible service worker registration and offline caching.
7. The app uses browser speech synthesis for some lesson pronunciation. This is NOT the same as recorded male and female human teachers.

INSTALLATION BEHAVIOUR
The in-page INSTALL button has been removed as requested. Visitors should use Chrome's own Install app option from the browser menu or its installation affordance when Chrome decides the PWA is eligible. The app cannot force Chrome to display that browser control on every visit. Confirm the deployed GitHub Pages site is HTTPS, then open it in updated Chrome and check the three-dot menu > Install app (or Add to Home screen, depending on device/browser).

ITEMS THAT REQUIRE EXTERNAL MATERIAL OR FURTHER REVIEW
- Real male and female human recordings for Arabic letters, Harakat, Wudu and Salah are not included. They require supplied recordings or properly licensed audio files; browser text-to-speech must not be represented as human recordings.
- Hausa translations for all 267 Hisnul Muslim entries are not complete. Only selected entries have been translated; remaining entries are transparently marked.
- Review Islamic lesson content, transliterations, counts and translations with a qualified teacher before public release.

TESTING
JavaScript syntax checks and local asset/reference checks should be completed before deployment. This package has not been tested on the live GitHub Pages URL or across physical Android devices. After uploading, clear/update the old PWA cache and test installation, offline launch, audio, saved progress and navigation on the target phone.
