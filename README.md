# 🌙 Little Muslim Learners

A fun, colourful web app that teaches children **Arabic letters (Huruf)**, **Wudu (Alwala)**, **Salah (Sallah)** and **Azkar** step by step. It works in **English, Hausa and Arabic**: tap the language buttons at the top of the page.

Built by **ATM Digital Solutions & Services** (*Learn • Collaborate • Achieve*).

## Features
- 🔤 **Arabic Letters**: all 28 letters with name, example word, picture and audio, plus the short vowels (Harakat)
- 💧 **Wudu / Alwala**: 11 simple steps with the dua after wudu
- 🕌 **Salah / Sallah**: rakah table for the 5 daily prayers and the full prayer step by step (Takbir, Al-Fatiha, Ruku, Sujud, Tashahhud, Tasleem)
- 📿 **Azkar**: after-prayer tasbih with a tap counter, Ayatul Kursi, and daily duas (waking, eating, sleeping)
- 🎯 **Quiz**: random 5-question quiz (Wudu, Salah, Azkar and letters)
- ⭐ **Stars**: rewards saved on the child's device
- 🔊 **Listen** buttons (use the browser's built-in Arabic voice if the device has one)
- 🌍 English, Hausa and Arabic (Arabic switches the page to right-to-left)
- 📱 Works on phones, tablets and computers, and needs no internet once loaded

## Run it
Open `index.html` in any browser. No installation needed.

## Put it on GitHub
```bash
git init
git add .
git commit -m "Little Muslim Learners"
git branch -M main
git remote add origin https://github.com/<your-username>/little-muslim-learners.git
git push -u origin main
```
Then on GitHub: **Settings → Pages → Source: Deploy from branch → main / (root) → Save**.
Your app will be live at `https://<your-username>.github.io/little-muslim-learners/`.
